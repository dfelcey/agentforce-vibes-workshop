### Option 2: Deploy Workshop to GitHub Pages
```bash
git init
git add .
git commit -m "Deploy Agentforce Vibes workshop"
git remote add origin https://github.com/USER/agentforce-vibes-workshop.git
git push -u origin main
```
Then enable GitHub Pages in Settings → Pages
